## 연출

Hoplite 원본의 32초 영상을 재생하고 반초 간격으로 장면을 살폈다. 노트북 덮개가 닫히는 동작을 밤 시간의 경계로 삼고, 다음 컷에서 세 기능이 차례로 체크되도록 박자를 잡았다. [Hoplite cloud handoff launch](https://prompt-motion.com/ryan-morr-ccc796)

문제 카드가 잠금 화면 알림 너비로 좁아진 뒤 같은 문구가 휴대폰에 도착한다. 해결 때 처음으로 큰 글자를 민트로 바꾸고, 마지막 화면에서는 주소가 움직이지 않는 채로 2초 이상 남는다.

## 실제 화면과 재현

로컬에서 실제 회원 웹을 띄우고 QA 데모 응답으로 홈과 문제 상세를 연다. React가 만든 홈 카드, 기능명과 상태, 복사 직전·직후 단추, 문제 흐름 두 행의 DOM을 읽어 앱의 CSS와 함께 영상에 배치한다. 응답 시간과 건수는 문제 카드에만 나오는 데모 값이다. 노트북 외형과 휴대폰 잠금 화면은 영상용 연출이다. [홈과 문제 상세](../../web/src/Monitor.tsx) · [데모](demo.mjs) · [화면 추출 및 검수](production.spec.mjs) · [동작](motion.js)

로컬 Chrome, FFmpeg, ffprobe, Noto Sans KR 가변 TTF를 사용한다. Windows 기본 글꼴 위치 외에는 작업 폴더의 `assets/NotoSansKR-VF.ttf`에 둘 수 있다. 아래 명령은 레포 루트에서 실행한다. 패키지, 생성한 HTML과 글꼴, 임시 프레임은 커밋 대상에서 제외했다.

```powershell
npm.cmd --prefix marketing/reel-02 ci --cache marketing/reel-02/.cache/npm --ignore-scripts --no-audit --no-fund
npm.cmd --prefix marketing/reel-02 run compose
npm.cmd --prefix marketing/reel-02 run render
npm.cmd --prefix marketing/reel-02 run qa
```

HyperFrames 0.9.85의 통계 및 업데이트 확인을 끄고 60fps로 렌더한다. 검수 명령은 최종본의 영상·음성 트랙 수, 길이, 프레임 수와 크기를 확인한다. 타임라인은 최종 MP4의 0초부터 29초까지를 왼쪽에서 오른쪽으로 읽는다.

최종본에서 뽑은 1초 간격 30장을 직접 확인했다. 첫 렌더의 장면 경계에 잠깐 겹쳤던 제목을 순차 교대로 수정했다. 재렌더 후 1,800프레임의 구성 시각별로 두 장면의 동시 노출과 주요 문구의 안전 영역 이탈이 각각 0건이었다.
