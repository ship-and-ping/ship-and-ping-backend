# 프롬프트 기록

| 위치 | 무엇을 기록하나 |
|---|---|
| [v1](v1-기획요청.md), [v2](v2-방향전환.md) 등 `v번호-주제.md` | 사람이 매니저에게 준 기획 요청. 방향이 바뀌면 다음 번호로 저장한다. |
| `tasks/T번호.md` | 구현 담당자가 받은 작업 지시문 전문. 번호는 구현 계획의 작업 번호를 쓴다. [T1 지시문](tasks/T1.md) |

각 프롬프트 파일에 **바꾼 이유** 칸을 둔다. 첫 버전이면 최초 요청의 목적을, 다음 버전이면 이전 지시에서 무엇을 왜 바꿨는지 적는다. 작업 지시문 원문은 보존하고 이유는 별도 칸에 쓴다.

## v1에서 v2로 바꾼 이유

v1은 제작자가 고른 기능 하나의 성공 여부를 추적했다. 제출자는 앱을 운영하며 미리 고르지 않은 기능에서도 문제가 생긴다는 점을 경험했다. v2에서는 앱 전체를 자동으로 지켜보고, 중요한 기능만 실제 저장까지 확인하도록 범위를 바꿨다. 제작자가 직접 경보를 관리하는 부담도 줄이기로 했다. 이후 무료 플랜 조사로 바뀐 엔진 결정은 [PRD v1.1](../PRD.md)에 따로 기록했다.
