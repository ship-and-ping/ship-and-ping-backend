## 사용자 결정 (2026-11-26, 그대로)
로그인 방식 선택지 중 **"아이디·비밀번호 추가"**. 아이디는 **이메일**로 한다(따로 아이디를 만들지 않음). 기존 이메일 로그인 링크는 **유지**, Google 로그인 예정도 그대로.

## 만들 것 (테스트 먼저)
1. **로그인 화면(S1)**: 이메일 + 비밀번호로 로그인(기본), 아래에 "비밀번호 없이 메일 링크로 받기"(기존 방식). 실패 문구는 쉬운 말이고 **계정이 있는지 알려 주지 않는다**("이메일이나 비밀번호가 맞지 않아요"). 비밀번호 보기 토글, 제출 중 중복 방지.
2. **가입**: 이메일·비밀번호(8자 이상, 너무 쉬운 것 안내)·비밀번호 확인 → "확인 메일을 보냈어요"(Supabase 가입 확인 메일 — 이미 쉽앤핑 디자인 적용됨). 이미 가입한 이메일이어도 같은 안내(계정 존재 노출 금지).
3. **비밀번호 찾기**: 이메일 입력 → 재설정 메일(Supabase `resetPasswordForEmail`, redirectTo = 현재 사이트 `/reset-password`) → `/reset-password`에서 새 비밀번호 2번 입력 → 완료 후 앱 목록. 링크 만료·이미 사용 시 다시 요청 안내.
4. **내 계정(S11)**: 비밀번호 바꾸기(현재 세션에서 `updateUser`), 링크로만 가입해 비밀번호가 없는 회원은 "비밀번호 만들기". 로그인 방법 표시 갱신.
5. **문구·문서 갱신**: 소개 페이지 "비밀번호를 만들지 않아도 돼요" 등 로그인 방식 설명을 "이메일과 비밀번호, 또는 메일 링크로 로그인해요"로. 기능명세서(버전 올리고 변경 이유 = 위 사용자 결정), `docs/monitoring-service-ux.md` S1·S11 흐름·상태 표, PRD 해당 줄.
6. **메일 양식**: `supabase/templates/`(없으면 만든다)에 비밀번호 재설정 메일 HTML을 로그인·가입 확인 메일과 같은 디자인으로 만든다. 기준 HTML은 매니저가 운영에 넣은 것: 진보라 머리 카드(#261B40) + 양 그림(`https://raw.githubusercontent.com/ship-and-ping/ship-and-ping-backend/main/docs/design/brand/ship-and-ping-sheep.png`, 64px, 민트 테두리) + "쉽앤핑 / 양이 대신 지켜봐요" + 제목 두 줄 + 본문 문장마다 한 줄(`word-break:keep-all`) + 라벤더 버튼(`{{ .ConfirmationURL }}`, nowrap) +  안내 상자("이 링크는 한 번만 쓸 수 있고 곧 만료돼요." / "요청하지 않았다면 이 메일은 무시해 주세요.") + 바닥글 "쉽앤핑 · 내 앱을 대신 지켜보는 모니터링". 표(table) 기반, 인라인 스타일만. 로그인(magic link)·가입 확인 양식도 같은 폴더에 같은 규칙으로 저장(제목: "쉽앤핑 로그인 링크예요", "쉽앤핑 가입을 확인해 주세요", 재설정은 "쉽앤핑 비밀번호를 다시 정해 주세요"). 운영 반영은 매니저가 한다.
7. 디자인: 쉽앤핑 토큰만, 한글 줄바꿈, 390px 넘침 없음, 키보드·초점, 자동 완성 속성(`autocomplete="email"`, `current-password`, `new-password`). `npm run qa:shots`로 로그인·가입·재설정·S11 캡처를 `docs/design/qa/after/`에.
8. 이 지시문을 `prompts/tasks/T22.md`로 복사, 위임 로그 `docs/위임로그/김태형.md`에 6칸 항목, PR 본문에도.

## 지킬 것
- 비밀번호는 Supabase Auth에만 — 앱 코드·DB 테이블·로그·localStorage에 저장하지 않는다. 화면에 비밀번호를 다시 표시하지 않는다(보기 토글 제외).
- 실제 외부 서비스(운영 Supabase `tzkngvpsygkiegvcagsj`, Resend) 호출 금지 — 테스트는 가짜.
- 키 모양 리터럴 금지, `.env` 커밋 금지, 화면 출력은 공용 표시 함수만, `dangerouslySetInnerHTML` 금지.
- 운영 Supabase 설정(비밀번호 로그인 켜기, 최소 길이, 재설정 메일 양식, 리디렉트 주소)은 매니저가 한다 — PR 본문 '운영에서 바꿀 설정'에 목록으로.
