## 사용자 결정 (2026-11-26)
앱 등록(S3)의 "앱 주소"가 꼭 웹사이트 주소를 넣어야 하는 것처럼 보인다 → **"앱 주소 (선택 · 웹사이트나 스토어 링크)"**로 바꾸고, 모바일 앱이면 연결 화면에서 "서버 있음"을 고르라는 안내를 넣는다.

## 할 일 (테스트 먼저)
1. S3 앱 등록 화면: 라벨 "앱 주소 (선택 · 웹사이트나 스토어 링크)", 칸 아래 도움말 "비워 둬도 돼요. 연결은 주소가 아니라 다음 단계의 연결 키로 해요." 예시 placeholder는 `https://` 정도. 기존 https 형식 검사는 유지(플레이스토어 `https://play.google.com/...`, 앱스토어 `https://apps.apple.com/...` 통과 테스트).
2. S4 연결 화면(서버 있음/브라우저만 고르는 곳): "휴대폰 앱(플레이스토어·앱스토어)이라면 앱 서버에서 기록을 보내도록 **서버 있음**을 골라 주세요. 휴대폰 앱 코드는 바꾸지 않아도 돼요." 안내 한 줄.
3. S10 앱 설정의 주소 칸도 같은 라벨·도움말.
4. 기능명세서 S3·S4 문장, UX 문서 해당 줄 갱신(사용자 결정 인용), `prompts/tasks/T33.md`, 위임 로그 T33 행. `npm run qa:shots`로 S3·S4 캡처를 `docs/design/screens/` 해당 번호에 갱신.
