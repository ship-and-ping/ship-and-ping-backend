4. 카드 번호: **아직 결정 안 됨** — 규칙을 넣지 말고 PR 본문 '사용자 결정 필요'에 선택지(넣음: 13~19자리+Luhn 검사 / 안 넣음)와 오탐 예시만.
5. DB advisor 경고 `private.sum_hist` search_path 미설정 → 새 마이그레이션으로 `set search_path=''`(동작 불변, pgTAP로 확인).
