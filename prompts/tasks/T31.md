# 쉽앤핑 T31 — 배포 막힘 수정: 슬랙 비밀값을 선택으로

너는 Orca 작업 에이전트(Codex)다. 새 작업 폴더에서 일하고 PR까지 만든다. **머지 금지.** 이 기기(Windows)는 Rust 테스트 실행이 막힌다 — Rust·DB 테스트는 PR CI로 확인.
명령은 경로를 그대로 하나씩(셸 변수·명령 치환·인터프리터 한 줄 실행 금지), 파일은 Read·Write(편집) 도구로.

## 배경
첫 운영 배포(GitHub Actions Deploy to Cloudflare, target=worker)가 `wrangler deploy --env production`에서 실패했다: "The following required secrets have not been set: SLACK_CLIENT_ID, SLACK_CLIENT_SECRET". 사용자 결정: 슬랙 연결은 나중에(이번 배포에서 제외). 코드는 이미 `notify.rs`의 `setting()`이 빈 값/없음을 None으로 처리해 슬랙만 꺼진다.

## 할 일
1. `worker/wrangler.toml`의 `[env.production.secrets] required`에서 `SLACK_CLIENT_ID`, `SLACK_CLIENT_SECRET`를 뺀다(나머지 5개 유지).
2. 슬랙 비밀값이 없을 때 동작 확인: 슬랙 연결 시작 요청(`/v1/slack/...`)이 내부 오류 없이 "슬랙 연결이 아직 준비되지 않았어요" 같은 안내(웹이 처리할 수 있는 상태 코드)로 응답하는지 — 이미 그렇다면 테스트만 추가, 아니면 최소 수정 + 테스트. 웹 알림 설정 화면에서 슬랙 연결 단추가 이 응답을 쉬운 말로 보여 주는지 확인(웹 수정이 필요하면 최소로).
3. 기존 테스트(`worker/src/cron.rs` 등 wrangler.toml을 읽는 설정 일치 테스트)가 있으면 새 목록에 맞춘다.
4. `docs/deploy.md`에 "슬랙은 선택: 나중에 SLACK_CLIENT_ID·SLACK_CLIENT_SECRET를 Worker Secret으로 넣으면 켜짐" 한 줄.
5. `prompts/tasks/T31.md`, 위임 로그 T31 행.

## PR
