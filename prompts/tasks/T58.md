## 바꿀 것
1. **토스트 컴포넌트**: 화면 레이아웃을 밀지 않는 고정 위치 토스트(PC 오른쪽 아래 또는 위 가운데, 390px은 위 가운데 전폭-16px). 들어올 때 살짝 아래→위 + 페이드(200~250ms, ease-out), 나갈 때 더 짧게. 4~5초 뒤 자동으로 사라짐, 마우스 올리면 멈춤, 닫기 버튼, 휴대폰은 옆으로 밀어 닫기(가능하면). 상태 아이콘(성공·안내·문제) + 제목 한 줄 + 짧은 설명. `role="status"`/`aria-live="polite"`. reduced-motion이면 페이드만.
   - 라이브러리: 직접 구현 또는 `sonner`(작고 React 19 지원) 중 택1, 근거를 보고에. 새 의존성이면 비밀값·라이선스·크기 확인.
   - 앱 안의 다른 notice·저장됨·복사됨 안내도 같은 토스트로 통일(찾아서 목록화).
2. **로그아웃 문구**: 제목 `로그아웃했어요`, 설명 `푸시 알림은 다시 로그인하면 알림 설정에서 켤 수 있어요.`(더 짧게 다듬어도 됨). 이 기기만 로그아웃한 경우도 동일 형식.
3. **로그인 화면 생동감(과하지 않게)**: 진입 시 왼쪽 카드·오른쪽 폼이 짧게 순서대로 올라옴(stagger 60~80ms), 양 캐릭터가 아주 천천히 숨 쉬듯 움직이거나 깜빡임, 버튼 누름 반응(scale 0.98), 입력칸 초점 테두리 전환. `docs/homepage-effects-12.md`에 맞는 것만. reduced-motion이면 전부 끔. 레이아웃 흔들림(CLS) 없게 transform·opacity만.
