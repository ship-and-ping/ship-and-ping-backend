## 동시에 도는 작업 — 파일 겹치지 않기
T22(PR #20, 이메일·비밀번호 로그인)가 `PRD.md`, `docs/specs/`, `docs/monitoring-service-ux.md`, `web/`, `supabase/templates/`, `docs/위임로그/김태형.md`(T22 행)를 고친다. 너는 **PRD·기능명세서·UX 문서·web·supabase를 고치지 않는다.** 위임 로그는 맨 마지막 단계에서 `git fetch origin` + `git merge origin/main`(rebase·강제 push 금지) 뒤 정리한다 — T22가 아직 main에 없으면 T22 행은 건드리지 말고 PR 본문에 적는다.

## 할 일
1. **README 실행 방법** 3칸("T2·T3·T5 완료 후 채움")을 실제로 채운다 — 수집·판정 Worker(로컬 실행·테스트·필요한 비밀 설정 이름만, 값 없음), Supabase 로컬 DB(`npx supabase@2.75.0 start`·`test db`·마이그레이션), React 웹(`web/.env.local` 변수 이름과 예시 가짜 값, `npm ci`·`npm run dev`·`npm test`·`npm run qa:shots`), 그리고 `bash scripts/verify-local.sh`(T10 일괄 확인). 명령은 레포의 실제 스크립트·워크플로와 맞춰 검증한다(가능한 것은 실제로 돌려 본다).
2. **고른 메뉴 표** 최신화: Q6 보관(지금: 5분 요약 7일 → 시간별 30일 → 하루 요약 1년, KST 날짜), 베타 상한(전체 자동 기능 100개·앱당 20개·회원당 앱 3개, DB 300MB 경보), D4 로그인 — **사용자 결정 2026-11-26 "아이디·비밀번호 추가"**: 이메일·비밀번호 + 메일 링크(유지) + Google(예정). 메일은 지금 Resend 테스트 발신이라 가입 메일 주소로만 간다(도메인 연결은 나중, 사용자 결정). 출처 문서·PR 링크.
3. **AI 사용 지도** 최신화: "예정"을 실제로. 작업마다 어느 AI(Codex Astra 6.2 구현 / Claude reviewflow 교차 검증 / Claude Code 매니저)가 무엇을 했고 사람이 무엇을 결정했는지. 대상: T1~T10, T21, T22(진행 중이면 '진행 중'), D1~D6(디자인 시안·QA·모션), S1·S2, 운영 작업(원격 Supabase 마이그레이션 적용, Resend SMTP·메일 양식 — 매니저가 브라우저로 설정). 검증에서 미통과 → 수정한 사례(예: T10 버전 가림, T21 탈퇴 결과 불명, D6 1차가 얕아 2차)를 짧게.
4. **위임 로그** `docs/위임로그/김태형.md`: 모든 작업 행이 6칸을 다 채웠는지, 빠진 작업(T1~T10·T21·D1~D6·S1·S2) 보충. 근거는 `prompts/tasks/*.md`, PR 본문, `git log`. **배운점 한줄은 초안으로 쓰고 PR 본문 '사용자 확인 필요'에 목록으로**(제출자 본인 말로 고칠 수 있게).
5. `prompts/README.md`: v1→v2 바꾼 이유가 분명한지, `prompts/tasks/` 목록(T1~T22·D1~D6·S1·S2) 최신.
