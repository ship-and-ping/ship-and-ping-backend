# 쉽앤핑 T61 — "휴대폰으로 알림 받기" 온보딩: 메일로 설치 안내 받기 → Safari 설치 → 홈 화면 앱 로그인 → 푸시 켜기

너는 Orca 작업 에이전트(Codex)다. 새 작업 폴더에서 일하고 PR까지 만든다. **머지 금지.** Windows — Rust·DB 테스트는 CI, 웹 테스트·캡처는 로컬.
명령은 경로를 그대로 하나씩(셸 변수·명령 치환·인터프리터 한 줄 실행 금지), 파일은 Read·Write(편집) 도구로.
T58(`App.tsx` 로그인 복귀·토스트, PR #53)이 진행 중 — 겹치는 곳은 최소로, 새 화면은 새 파일(예: `web/src/InstallGuide.tsx`)로. 토스트는 T58 것을 쓸 수 있으면 쓰고, 아니면 기존 방식 유지 후 PR 본문에 적기.

## 사용자 요청 (2026-11-28)
"메일로 보내서 PWA 설치하는 온보딩 화면을 메일로 받기 해서, 클릭하면 사파리에서 PWA 다운받는 게 나올 수 있게 할 수 있나?"
배경: 알림은 푸시 우선(홈 화면 앱). 지금은 설치 방법이 알림 설정 푸시 칸에 몇 줄뿐이고, PC로 가입한 사람이 휴대폰으로 넘어갈 길이 없다(T60 검토: 홈 화면 앱 첫 화면 6~7점). 발표에서 "알림 받고 → AI 요청문 복사" 장면이 필요하다.

## 흐름
1. **진입점**: 가입 직후 단계·앱 홈 상단(푸시 미설정일 때만, 닫기 가능)·알림 설정에 "휴대폰으로 알림 받기". 화면에 **QR 코드**(설치 안내 주소, 외부 서비스·CDN 없이 로컬 생성 — 의존성 추가 시 크기·라이선스 확인) + **"설치 안내 메일 받기"** 버튼.
2. **메일**: 로그인한 본인 메일로만 발송(주소 입력 받지 않음), 기존 Resend 경로 재사용, 계정당 10분 1회·하루 5회 제한. 본문: 큰 버튼 "아이폰에서 열기" → `<WEB_ORIGIN>/install`. **메일 링크에 로그인 토큰·키를 넣지 않는다**(메일 앱 미리보기·전달로 새는 것 방지). Gmail 앱 등 내장 브라우저에서 열릴 수 있으니 "Safari로 여세요" 안내 한 줄.
3. **/install 안내 화면(로그인 없이 열림)**: 기기 판별 후 분기 —
   - iPhone Safari: 3단계 그림 안내(공유 버튼 위치를 화면 아래로 가리키는 화살표 → "홈 화면에 추가" → 추가). iOS 16.4 미만이면 업데이트 안내.
   - iPhone 다른 브라우저/메일 내장 브라우저: "Safari로 열어 주세요" + 주소 복사 버튼.
   - Android Chrome: `beforeinstallprompt`로 "쉽앤핑 설치" 버튼.
   - PC: QR 코드로 휴대폰에서 열기.
   - 이미 홈 화면 앱으로 열렸으면(standalone) 다음 단계로 바로.
   - iOS는 설치 창을 자동으로 띄울 수 없다 — 안내만 한다(사용자에게 보고서에 명시).
4. **홈 화면 앱 첫 실행**: iOS 홈 화면 앱은 Safari와 로그인 저장소가 분리돼 다시 로그인해야 한다. 메일 링크는 Safari로 열려 앱으로 돌아오지 않으므로 **메일로 받은 6자리 코드 로그인**(Supabase 이메일 OTP, 기존 가입자만, 시도 제한)을 홈 화면 앱 로그인 화면에 추가. 비밀번호 로그인도 유지.
5. **푸시 켜기 → 시험 알림**: 로그인 직후 "알림 켜기" 한 화면(권한 요청은 버튼 탭으로만), 성공하면 "시험 알림 보내기"(기존 queue_test_push) → "알림이 왔나요? 왔어요 / 안 왔어요(해결 방법)". 완료 시 앱 홈으로.
6. VAPID 키가 아직 없으면(운영 미설정) 푸시 단계에서 "알림 준비 중" 상태를 정직하게 보여 주고 오류로 끝내지 않는다.
