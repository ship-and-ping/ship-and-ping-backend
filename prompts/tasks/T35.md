# 쉽앤핑 T35 — 클립보드 실패 시 키 노출 안내 (T34 검수 잔여)

너는 Orca 작업 에이전트(Codex)다. 새 작업 폴더에서 일하고 PR까지 만든다. **머지 금지.** Windows — 웹 테스트·빌드는 로컬.
명령은 경로를 그대로 하나씩(셸 변수·명령 치환·인터프리터 한 줄 실행 금지), 파일은 Read·Write(편집) 도구로.

## 배경 (매니저 결정)
T34로 연결·키 교체 요청문에 앱 키가 들어간다. 클립보드 복사가 막히면 대체 선택 상자에 전문이 보여 서버 키(`sp_srv_…`) 원문이 화면(DOM)에 나타난다(`web/src/Connect.tsx:383`, `web/src/AppSettings.tsx:258`). 사용자 본인 화면이라 **보여 주는 것은 허용**하되 안전하게.

## 할 일 (테스트 먼저)
1. 대체 선택 상자에 키가 포함된 요청문을 보여 줄 때: 기본은 키 줄을 `••••`로 가린 채 표시하고 [키 포함해서 보기] 단추(누를 때만 원문)와 경고 "화면을 공유 중이라면 먼저 공유를 멈춰 주세요. 이 글에는 앱 키가 들어 있어요." 복사 실패 안내는 쉬운 말로(브라우저 권한 허용 방법 한 줄).
2. 상자를 닫거나 화면을 떠나면 원문을 상태에서 지운다.
3. 기존 불변식 테스트('서버 키 복사가 거절되어도 DOM에 원문 없음')를 새 규칙으로 바꾼다: [키 포함해서 보기]를 누르기 전에는 원문이 DOM에 없다.
4. `prompts/tasks/T35.md`, 위임 로그 T35 행.
