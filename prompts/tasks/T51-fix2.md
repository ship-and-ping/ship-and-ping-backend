## 고칠 것 (재검수 남은 지적)
1. 짧은 커밋 규칙 `^[0-9a-f]{7,12}$`가 **숫자만 10~12자리**(예: 전화번호 01012345678)도 보여 줌 → 짧은 커밋은 **a–f 글자와 숫자를 둘 다 포함**할 때만 표시. 숫자만이면 빌드 번호 규칙(1~9자리)만 적용, 그 이상은 가림.
2. semver 접미부 `[0-9A-Za-z.]{1,20}`에 AWS 키 ID(AKIA…16자)가 들어갈 수 있음 → 접미부는 **소문자 표준 표기만**: `-(alpha|beta|rc|dev|pre|build)(\.?\d{1,6})?` 와 `+\d{1,9}` 정도로 제한.
3. 짧은 hex 키(7~12자)는 엔트로피가 낮아 커밋과 구분 불가 — 수용, 코드 주석과 PR 본문에 한계로 기록.
4. 기능명세서(`docs/` 중 재검수가 지적한 250·304~306·372·378행)의 "형식 불일치 원문을 데이터 블록으로 옮긴다"는 옛 규칙을 새 허용 목록 규칙으로 갱신.
웹·Worker 같은 규칙으로, 회귀 테스트(전화번호 형태 가림, v1.0.0-AKIA… 가림, 1.2.3-rc.1 표시, 1a2b3c4 표시) + 변형 검사.
