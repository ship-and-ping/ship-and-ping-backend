# 쉽앤핑 T2 — Rust Worker PoC (기록 받기·정제·합산, 처리 시간 측정)

너는 Orca 작업 에이전트(Codex)다. 새 작업 폴더에서 일하고 PR까지 만든다. **머지하지 않는다.** 같은 시간에 T3(DB, `supabase/` 폴더)이 다른 작업자에게 맡겨져 있다 — **맡은 파일만** 고친다.

## 먼저 읽기
- `AGENTS.md`(레포 규칙), `PRD.md` v1.1 표
- `docs/specs/2026-11-24-ship-and-ping-feature-spec.md` 0장(D1·D2), 1장, 4장(수집 데이터·정제·저장 형태), 5장(수신 방식), 10장 C5
- `docs/research/2026-11-24-free-tier-constraints.md` 1·2장(Workers 무료: CPU 10ms, Rust 제약)
- `db.md`의 `stats_5m`(hist 16구간)과 RPC `ingest_batch`

## 목표
PoC로 **"Rust Worker가 64KB·100건 묶음을 CPU 10ms 안에 처리할 수 있나"**를 판단할 근거를 만든다. 실패하면 대안을 보고한다.

## 맡은 파일
- `worker/` 전체(새 Rust 프로젝트), `.github/workflows/worker.yml`(새 파일), `prompts/tasks/T2.md`
- 손대지 않는 것: `supabase/`, `web/`, `.github/workflows/ci.yml`, `docs/위임로그/김태형.md`(이번엔 PR 본문에 6칸을 쓴다 — 다음 작업이 합친다), `README.md`

## 할 일 (테스트 먼저)
1. 도구: Rust(rustup 공식 설치), `wasm32-unknown-unknown` 타깃, `worker-build`, wrangler(npx). 없으면 설치하고 설치한 것·버전을 보고. 모두 무료.
2. `worker/`: workers-rs(`worker` crate 최신 0.x) 프로젝트, `wrangler.toml`(비밀값 없음, `.dev.vars.example`만).
   - `POST /v1/ingest`: 기능명세서 5.1 중 PoC 범위 — 헤더 `Authorization: Bearer sp_pub_…/sp_srv_…` 형식 검사(키 진위 확인은 T4, 지금은 해시 계산까지), 본문 ≤64KB·≤100건, 4.1 필드 검증, 4.3 정제(route `:id` 치환·쿼리 제거, error_message 가림·300자, ts ±24h), 4.4 합산(앱·route·version·5분 칸별 total·failures(5xx·예외)·client_errors(4xx)·duration_sum·hist[16]), 응답 202 `{accepted, dropped}` / 400 / 401 / 413.
   - Supabase 호출은 trait 뒤로 숨긴다. 기본 구현은 "합산 결과 JSON을 만들어 RPC `ingest_batch`로 보낼 준비까지"(실제 fetch는 `SUPABASE_URL`·`SUPABASE_SECRET_KEY` 환경값이 있을 때만, 없으면 건너뜀).
   - 순수 로직(검증·정제·합산)은 wasm 없이 `cargo test`로 도는 별도 모듈.
3. 테스트: 정제(이메일·전화·Bearer·sk_·eyJ 가림, UUID·숫자·긴 토큰 → `:id`), 검증 실패 경우, 합산 결과, 64KB·100건 경계, 변형 검사(정제 규칙 하나를 빼면 테스트가 실패하는지 확인 후 복구).
4. 측정 (`worker/BENCH.md`에 기록):
   - 네이티브: 64KB·100건 묶음 처리 시간(여러 번, 중앙값·최댓값).
   - wasm: `worker-build --release` 결과 크기(압축 전·gzip), 가능하면 `wrangler dev`(로컬)에서 같은 묶음 처리 시간.
   - Cloudflare 실제 CPU 시간은 사용자 Cloudflare 계정이 필요하다 → "계정 생긴 뒤 측정 방법"을 단계로 적고 미측정으로 표시. 추측값을 측정값처럼 쓰지 않는다.
   - 판단: 10ms 안에 들어올 가능성(근거와 함께), 위험하면 대안(묶음 상한 낮추기 등).
5. CI `.github/workflows/worker.yml`: `worker/**` 변경 시 `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo test`, wasm 빌드. 외부 액션은 커밋 SHA로 고정.
6. `worker/README.md`: 실행·테스트·빌드 방법.
7. 이 지시문을 `prompts/tasks/T2.md`로 저장.
