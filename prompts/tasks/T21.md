## 만들 것 (테스트 먼저)
1. **S10 앱 설정** (`/apps/:id/settings`): 이름·주소 수정, 기능 이름표 편집·숨긴 기능 되살리기, 키 접두만 표시 + [재발급](이전 키 24시간 유지 안내) + [폐기](즉시, "최대 5분 안에 멈춰요" 안내), 주소 형태 200개 초과 "기타" 안내, [앱 삭제](앱 이름을 정확히 다시 적어야 활성 — 디자인 시스템 확인 입력 규칙). 이미 있는 DB RPC를 우선 쓰고, 없으면 새 마이그레이션(번호 20261126100000번대, 본인 앱만, search_path='', revoke/grant).
2. **S11 내 계정** (`/account`): 계정 정보(로그인 이메일·가입일·로그인 방법), 앱마다 알림 받을 곳 요약, 앱 수 "n개 / 3개", 로그아웃, 회원 탈퇴 — 지워지는 것(실제 앱 수대로) 확인 → 로그인 이메일 다시 적기(정확히 같을 때만 활성) → [모든 앱과 기록을 지우고 탈퇴] → "탈퇴하는 중"(입력 잠금) → 완료: S1 + "탈퇴를 마쳤어요" 띠 / 실패: "탈퇴를 마치지 못했어요. 계정은 아직 남아 있고 로그인도 돼요" + [다시 시도](남은 삭제 이어서), 응답 끊김이면 10초 간격 확인·2분 뒤 재시도(명세·UX 문서 기준).
3. **회원 탈퇴 서버 경로 (Worker)**: 로그인 세션(JWT)으로 호출, 세션 사용자 = 탈퇴 대상 확인(본인만), 앱·기록·키·알림 연결(Vault 포함) 삭제 → Supabase Auth 사용자 삭제(서버 비밀 키는 Worker 비밀 설정에서만 읽음, 코드·로그·응답에 없음). 중간 실패 시 다시 호출하면 남은 것부터 이어서(멱등). 응답에 내부 정보 없음. Rust 테스트 + 로컬 통합(T10 방식 재사용).
4. **메뉴 연결**: '준비 중' 표시 제거, PC 왼쪽 메뉴·휴대폰 머리말 계정 아이콘·글자 200% [메뉴]에서 S10·S11로.
5. **C13·C14 재검증**: `scripts/t10-scenario.mjs`(또는 새 시나리오)에 S10 앱 이름 변경·키 폐기·앱 삭제, S11 탈퇴(확인 입력·실패 재시도·완료 후 키 401)를 넣고 `docs/verification/2026-11-26-T10.md`의 C13·C14 판정을 갱신.
6. 디자인: 쉽앤핑 토큰만, 한글 줄바꿈(keep-all), 390px 넘침 없음, 키보드·초점, 위험 단추는 위계 맞게(주 행동 하나), 설정 화면엔 양 없음. 가능하면 `web/qa/`의 `npm run qa:shots`로 S10·S11 캡처를 `docs/design/qa/after/`에 추가.
7. 이 지시문을 `prompts/tasks/T21.md`로 복사, 위임 로그 `docs/위임로그/김태형.md`에 6칸 항목 추가, PR 본문에도.
