## 매니저가 캡처(docs/design/screens/02-1440.jpg 등)에서 본 문제
- "비밀번호 보기"가 큰 별도 버튼이라 로그인 버튼과 위계가 같아 보인다 → 비밀번호 칸 **안 오른쪽의 작은 토글**(아이콘+화면 읽기용 이름 "비밀번호 보기/숨기기", aria-pressed)로.
- 버튼이 세로로 제각각 폭(로그인·메일 링크·Google)이라 어수선하다 → 주 행동 [로그인]은 칸 폭 전체, 그 아래 "또는" 구분선, 보조 행동(메일 링크로 받기, Google)은 같은 폭의 보조 버튼, 회원 가입·비밀번호 찾기는 한 줄 링크.
- "Google 로그인 예정"이 눌리지 않는 버튼처럼 보인다 → 운영 Google 설정 전에는 숨기거나, 보이려면 이유가 있는 안내 문구로(매니저 추천: 설정 전 숨김, 환경 변수나 설정 값으로 켬).
- 가입·비밀번호 찾기·재설정 화면도 같은 규칙으로 맞춘다.

## 지킬 것
쉽앤핑 토큰만, 한글 줄바꿈, 390px·키보드·초점·자동 완성 속성 유지, 계정 존재 비노출·비밀번호 비제어 입력 유지(T22 규칙), 기능 동작 변경 없음. 테스트 먼저(토글 aria-pressed·초점, 버튼 위계, Google 숨김 조건). `npm run qa:shots`로 로그인·가입·찾기·재설정 장면을 다시 찍어 `docs/design/screens/`와 README 썸네일이 최신이 되게.
