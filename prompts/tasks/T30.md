## 이 기기(Windows) 주의
Windows는 스마트 앱 컨트롤 때문에 Rust 테스트 실행 파일이 막힌다(os error 4551). **Rust(`cargo test`)·Supabase 로컬 DB(Docker) 테스트는 로컬에서 돌리지 말고 PR의 GitHub CI(worker·database 워크플로) 결과로 확인**한다. 웹 테스트(`npm test`)·빌드는 로컬에서 돌린다. Rust·SQL 변경은 CI가 통과할 때까지 push → `gh pr checks`로 확인하며 고친다.
