# 쉽앤핑 T30 수정 — 교차 검수 지적 (같은 브랜치·같은 PR #28)

너는 Orca 작업 에이전트(Codex)다. 브랜치 `fix/T30-error-followups`(PR #28)에 커밋을 더한다. **머지 금지.**
명령은 경로를 그대로 하나씩(셸 변수·명령 치환·인터프리터 한 줄 실행 금지), 파일은 Read·Write(편집) 도구로. 시작 전 `git fetch origin` → `git merge origin/main`.
**이 기기(Windows)는 Rust 테스트 실행이 막힌다 — `cargo test`·Docker DB 테스트는 로컬에서 돌리지 말고 PR CI로 확인**. 웹 테스트·빌드는 로컬.

## 고칠 것 (테스트 먼저, Rust·web·DB 세 곳 동일, 공통 시험표에 사례)
1. **높음 — 정상 이름 회귀**: opaque 판정을 값 전체에 적용해 `NullPointerException`, `QuotaExceededError`, `upstream_http_502`, `ERR_HTTP2_PROTOCOL_ERROR`, `submitPaymentForm`가 버려진다. 판정을 **조각 단위**로 바꾼다: 값을 `.`·`_`·`-`·공백으로 나눈 각 조각에 대해 — 16자 이상이고 (숫자가 섞였거나, 대소문자가 불규칙하게 섞여 사전 단어 조합으로 보이지 않거나, 알려진 토큰 접두사 `ghp_`·`gho_`·`ghs_`·`github_pat_`·`AKIA`·`ASIA`·`xox[abpr]-`·`AIza`·`sk-`·`glpat-`로 시작하면) 그 값 전체를 저장 안 함. **영문자만으로 된 CamelCase·대문자 단어 조각은 예외**(NullPointerException, QuotaExceeded, PROTOCOL). 시험표의 60자 저장 사례는 원래 형태(긴 정상 이름)로 되돌리고, 위 정상 이름 5개 저장 + 토큰 섞인 값 저장 안 함 사례 추가. **기대값을 바꿔 회귀를 숨기지 않는다.**
2. **높음 — 백필**: 마이그레이션 `20261126300000_opaque_diagnostics.sql`의 백필 UPDATE는 1번의 좁힌 기준으로만, 그리고 **기존 값이 새 기준에서 저장 안 함일 때만** NULL로(정상 값은 그대로). 백필을 검증하는 pgTAP 추가(정상 이름 유지, 토큰 값 NULL). 운영은 아직 미적용 — 같은 파일 수정.
3. **중간 — 우회**: `x.`+토큰, `pkg.`+토큰+`Error`, `한글 `+토큰 같은 조합이 1번 조각 판정으로 막히는지 시험표에.
4. **중간 — 테스트 효력**: `web/src/monitor.test.tsx:18`의 목 fetch가 select 열을 무시해 `monitor-data.ts`의 message 조회 추가를 되돌려도 통과 — select 열을 단언하거나 목이 요청 열에 따라 응답하게.
5. 낮음: 위임 로그 `docs/위임로그/김태형.md`의 표가 T24 7차 행부터 머리글 없이 깨져 렌더링 안 됨 — 표 머리글·구분 줄을 바로잡고 T30 행 정리.
