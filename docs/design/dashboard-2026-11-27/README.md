- 운영에서 보고받은 값은 트루바 ‘기타’의 **11월 27일 14:15~14:20 실패 30건**이다. 이 수치를 고정하고 성공 수·속도·다른 기능·이전 날짜를 예시로 구성했다. 운영 DB를 직접 조회한 결과와 구분해 모든 시안에 예시 표시와 기준 시각을 넣었다. [공통 데이터](fixture.js)
- 11월 26일 18:00~27일 18:00, 한국 시간 기준이다. ‘기타’는 72건 중 30건 실패했다. 14:00~15:00 막대는 아래 성공 20건과 위 실패 30건을 합친 50건이다. 10:00~11:00의 보통 시간은 5초이고, 그다음 구간은 1초다. 17:00~18:00에는 이 기능의 측정이 없다. 점이 없는 시간은 선으로 연결하지 않는다.
- 24시간은 1시간씩, 7일은 시작 시각부터 24시간씩 묶는다. 툴팁과 표에 시작·끝 시각을 표시한다. 기간별 보통 시간은 예시 측정 건수로 가중한 중앙값이다. 건수와 초를 각각의 축에 표시한다.
- 기타 기능 상세의 건수 축은 0·10·20·30·40·50건, 시간 축은 0~5초다. 바닥선 위 1px 점선 5줄, 막대 위쪽 반경 최대 4px, 이웃 막대 최소 간격 2px, 쌓은 값 사이 표면색 2px를 쓴다. 보통 시간은 2px 선과 지름 10px 점, 표면색 2px 테두리를 쓴다. 실패는 빗금과 범례로 표시한다. 단일 시간 계열은 제목이 범례 역할을 한다.
- 마우스를 올리거나 터치하면 해당 구간의 값을 읽을 수 있다. 키보드는 좌우·Home·End로 이동하고 Escape로 툴팁을 닫는다. 선 그래프에는 선택한 구간의 세로선이 뜬다. ‘표로 보기’는 24행 또는 7행을 보여 준다.

## 휴대폰과 검증 범위

- 390px에서는 상태가 첫 화면에 나오고, 그래프는 처음에 접혀 있다. 상단 상태 카드의 복사 버튼과 엄지로 누르는 하단 버튼이 같은 요청문을 복사한다. 주요 하단 버튼은 최소 48px다. 7일로 바꿔도 펼친 차트가 유지된다.
- Windows Edge 로컬 렌더링으로 현재 화면 18장과 시안 90장(기본 54장, 빈 화면·로딩·정상 36장)을 생성했다. 여기에 실사이트 원본 10장과 나란히 비교 6장을 더해 PNG는 모두 124장이다. 두 화면 너비와 두 테마에서 비교 페이지 선택, 가로 넘침, 이미지 로드, 실패 30건 툴팁, 시간 점 6개, 24시간·7일 표, 알림에서 문제로 이동, 복사 처리기에 전달되는 요청문을 확인했다. 휴대폰 첫 화면은 390×844px이고 펼친 차트 사진은 같은 너비의 전체 길이다. 휴대폰 너비의 브라우저 검증이며, 실기기 푸시 발송과 OS 클립보드 검사는 이번 시안 범위 밖이다.
- 현재 웹 캡처는 로컬 예시 응답을 사용한다. 시안의 앱 푸시·홈 화면 설치는 화면과 안내만 표현한다. 실제 알림 권한을 요청하거나 메시지를 발송하지 않는다.
