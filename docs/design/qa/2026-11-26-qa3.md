# T37 · 웹 UI·UX 3차 QA

## 수정과 확인

PC 대기 화면에 확인 숫자와 사용 방법을 묶고, PC 로그인 요청을 승인할 수 있는 시간이 10분임을 명시했다. 이메일 입력으로 돌아가는 버튼은 대기 중에 보조 행동으로, 만료·거절 뒤에는 주 행동으로 표시한다. 휴대폰은 요청 기기, 숫자를 맞추는 이유, 거절 방법 순서로 읽을 수 있다. 입력의 설명을 연결했고 처리 중·종료 상태를 별도로 표시한다.

연결 방식 선택을 밑줄과 채움색으로 표시하고 기존 키 경고를 두 요청문의 복사 버튼 위로 옮겼다. 키 교체 화면은 복사, 환경 설정, 재배포 세 단계로 나눈다. 키 공개·닫기와 직접 키 복사는 보조 버튼으로 표시한다. 슬랙 미설정 응답은 연결 버튼 아래에서 읽을 수 있다.

## 캡처 재현 (Windows PowerShell)

수정 전 화면은 PR 작업본의 루트에서 다음 명령으로 별도 폴더에 준비한다. 화면 코드는 기준 커밋 `898c47f`에서 가져오고, 이 커밋에 없던 3차 캡처 절차와 모의 응답만 최초 T37 커밋 `7724b83`에서 가져온다.

```powershell
git worktree add --detach ../ship-and-ping-qa3-before 898c47f
git -C ../ship-and-ping-qa3-before restore --source=7724b83 --worktree -- web/qa/shots.mjs web/qa/fixtures.mjs
Push-Location ../ship-and-ping-qa3-before/web
npm.cmd ci
node qa/shots.mjs qa3-before 2 31 32 33 34 35 36 37 38 39
Pop-Location
```

재현한 40장은 별도 폴더의 `docs/design/qa/qa3-before/`에 저장된다. 다음 명령은 PR 작업본의 루트에서 실행한다. 현재 화면을 `qa3-after/`에 기록하고, 비교 페이지에서 PR에 보관한 수정 전 캡처와 나란히 연다.

```powershell
Push-Location web
npm.cmd ci
node qa/shots.mjs qa3-after
node qa/check-gallery.mjs
Pop-Location
```
