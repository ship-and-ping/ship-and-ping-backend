## 데이터와 조작

상단의 기간은 앱 홈과 기능 상세의 수치와 그래프에 적용된다. 만족도 카드는 기능마다 자기 평소 p95를 적용한 뒤 성공 측정 건수로 합산한다. 예시의 24시간 만족도는 80%, 바로 아래 최근 1시간 만족도는 96%다. 여러 기능을 함께 본 홈에서는 기능 선택기로 한 기능을 고르면 그 기능의 평소 범위가 나타난다.

화살표와 Home·End로 키보드 위치를 옮기고 Esc로 닫는다. 터치는 누르고 가로로 끌며, 세로 스크롤과 핀치를 허용한다. 자동 새로고침은 기본 1분이고 탭을 다시 열면 선택한 주기로 재개한다. 조회가 실패해도 직전 데이터와 조회 기간을 유지한다.

공개 데모의 시계열은 한 시간 안에도 세밀한 굴곡을 보여준다. 쉽앤핑은 요약 구간을 선택하므로 점 사이의 원본 요청 시각까지 판독할 수 없다. 모바일 툴팁은 작은 화면에 다섯 값을 모두 표시해 열려 있는 동안 윗부분의 범례를 가릴 수 있다.

## 재현과 검증

웹 디렉터리에서 `node qa/grafana-reference.mjs`, `node qa/demo-insights.mjs`, `node qa/compare-panels.mjs` 순서로 실행한다. 공개 데모에는 익명으로 접속했고 쉽앤핑 화면은 같은 시각에 고정한 모의 기록으로 촬영했다.

단위 테스트에서 기본 주기, 숨김·복귀, 주기 변경·끔, 중복 요청, 실패 후 회복, 기간 전환 실패, 키보드·포인터 선택의 동기화를 검사한다. 공유 십자선을 한 패널에만 그린 변형은 반대 패널의 선 검사에서 실패했다. 숨긴 탭에서도 타이머를 돌린 변형은 요청이 2회에서 4회로 증가해 실패했다. 두 변형을 복원했다.

Edge에서 고친 뒤 사례의 앱 홈·기능 상세 모두 밝은·어두운 테마로 키보드와 마우스를 검사했다. 390px에서는 터치 드래그가 3번째에서 21번째 구간으로 옮겨지고 반대편 그래프도 21번째가 되는지, 모션 감소 설정에서 전환 시간이 0초인지 확인했다. axe의 WCAG 2 A·AA 및 2.1 AA 자동 검사에서 위반은 0건이었다.
