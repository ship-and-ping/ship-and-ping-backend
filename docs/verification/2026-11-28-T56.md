# T56 원격 MCP 조회 검증

앱 설정에서 발급한 AI 조회 키로 기존 Cloudflare Worker의 `/mcp`에 연결한다. 별도 서비스와 배포 비밀 설정은 필요하지 않다. 키가 허용하는 앱은 발급 때 결정된다.

| 확인 항목 | 구현 및 검증 |
|---|---|
| 전송 | [현행 Streamable HTTP](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http)의 JSON 응답과 [버전 협상](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning)을 적용했다. 최신 클라이언트는 `server/discover`, 2025-11-25·2025-06-18 클라이언트는 `initialize`로 시작한다. |
| 조회 | `web/mcp.test.ts`의 루프백 HTTP 클라이언트가 두 프로토콜의 초기 연결, 목록, 일곱 도구를 호출한다. DB 응답은 고정 데이터로 대체하고 실제 DB 권한과 결과는 `supabase/tests/mcp_read.sql`에서 확인한다. |
| 권한 | 회원용 발급·목록·폐기와 Worker 전용 조회 RPC의 권한이 다르다. 키 해시와 앱 범위, 3개 한도, 만료·폐기, 60회 제한, 접근 기록 보존을 DB 테스트에서 검증한다. |
| 앱 데이터 | 도구 설명과 결과에는 경고를 고정하고 앱 데이터는 구조화 필드에 담는다. 버전·조사 요청문은 웹 표시 함수를 공유한다. T54 테이블이 있는 경우 숫자 자원 지표만 반환한다. |
| 로컬 검증 | Windows 웹 전체 테스트·빌드·lint 통과. 별도 HTTP 왕복 검사에서 핸드셰이크와 조회를 확인했다. 추가 인자 검사 조건을 제거하자 앱 범위 인자 거부 테스트가 실패했고 원복했다. |
| 설정과 검수 범위 | 앱 설정의 AI 연결에서 키 발급·폐기·마지막 사용을 확인하고 Claude Code·Cursor·Codex의 사용자 설정 예시를 볼 수 있다. 실제 운영 키 발급이나 외부 클라이언트 계정 연결은 수행하지 않았다. |

브랜치에서 Rust Worker 빌드와 DB 테스트는 GitHub Actions가 실행한다.
