| 프롬프트 | 제품 구조를 설명하고 7개 질문(한도, Rust wasm 제약, DB 연결 방식, Grafana 한도·약관, 슬랙, 0원 이메일, JWT 검증)에 공식 URL을 붙여 답하고 확인 못 한 것은 표시하라 |

| 배운 점 | 초안 · 무료 한도와 회원 대상 서비스에 허용된 용도는 각각 확인해야 한다. |
